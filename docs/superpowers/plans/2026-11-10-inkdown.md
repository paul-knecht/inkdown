# Inkdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar app that converts a PDF of handwritten notes into a Markdown file next to it, started from Finder's right-click menu, a drop on the menu bar icon, or a file picker.

**Architecture:** A `Converter` splits the PDF into one-page PDFs with PDFKit, sends up to 4 at a time to Claude Sonnet through `ClaudeClient`, and assembles the page texts with `MarkdownAssembler`. A `ConversionQueue` owned by `AppDelegate` runs one PDF at a time and drives the status item and messages. All three entrances call `AppDelegate.convert(urls:)`.

**Tech Stack:** Swift 5, AppKit, PDFKit, Security, `URLSession`, XCTest. No third-party libraries.

**Spec:** `docs/superpowers/specs/2026-11-10-inkdown-design.md`

## Global Constraints

- Repo `~/Developer/inkdown`, local only. Branch `feature/inkdown`; merge into `main` with `--no-ff` at the end.
- Every commit message ends with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- The user is a beginner: plain-language explanation after each task; one sentence per commit, branch and merge. Simple code, a comment above each type and non-obvious function.
- macOS deployment target 14.0, App Sandbox off, `CODE_SIGN_IDENTITY = "-"`, `LSUIElement`, bundle ID `local.inkdown`. Project files are adapted from `~/Developer/glance`.
- Build: `xcodebuild -project Inkdown.xcodeproj -scheme Inkdown -derivedDataPath build build`; tests: same with `test`.
- Model ID `claude-sonnet-5-5` and its list price ($2 per million input tokens, $10 per million output tokens) live in constants in `ClaudeClient.swift`.
- The API key is never read, printed, logged or typed by Claude; tests use the Keychain service `local.inkdown.tests`.
- No automated test calls the real API. Only pages of the PDF being converted are sent to Anthropic.
- Load the `claude-api` skill before writing `ClaudeClient`; where the plan and the skill differ, the skill wins.
- Tell the user before a step that can trigger a macOS prompt.

## Review Focus

1. A PDF whose `.md` already exists → nothing is sent and nothing overwritten until the user answers. (Task 5 test on `OutputNaming`; Task 6 flow.)
2. One page fails for good → the rest still converts, the file contains `[PAGE N COULD NOT BE READ]`, and the result names the page. (Task 4 test.)
3. Wrong key or no credit on page 1 → the conversion stops at once, no further requests, no file. (Task 4 test.)
4. Cancel mid-way → no file written, queue cleared, icon back to idle. (Task 4 test for no output; Task 6 by hand.)
5. Pages finish out of order because 4 run at once → the file is still in page order. (Task 4 test.)

### Task 2: Splitting PDFs and assembling Markdown

**Files:** `Inkdown/PDFSplitter.swift`, `MarkdownAssembler.swift`, `OutputNaming.swift`; tests for each.

**Interfaces:**
- `enum PDFSplitter { static func pages(of url: URL) throws -> [Data] }` — throws `ConversionError.cannotOpen`, `.locked` (when `isLocked` or `isEncrypted` and not unlockable with an empty password), `.empty`. Each element is a valid one-page PDF.
- `enum MarkdownAssembler { static func assemble(_ pages: [PageResult]) -> String; static func clean(_ text: String) -> PageResult }`
  - `assemble`: for page N (1-based) `.text(t)` → `<!-- Page N -->\n\n` + t; `.unreadable` → `<!-- Page N -->\n\n[PAGE N COULD NOT BE READ]`; `.blank` → nothing. Pages joined by one blank line; file ends with one newline.
  - `clean`: trims whitespace; removes one surrounding code fence (```` ``` ```` or ```` ```markdown ````) if the whole text is wrapped in it; empty text or exactly `[BLANK PAGE]` → `.blank`; otherwise `.text`.
- `enum OutputNaming { static func defaultURL(for pdf: URL) -> URL; static func keepBothURL(for pdf: URL, exists: (URL) -> Bool) -> URL }` — `notes.pdf` → `notes.md`; keep-both → `notes 2.md`, then `notes 3.md`, … first that doesn't exist.

  - `PDFSplitterTests`: build a 3-page PDF in the test with PDFKit (pages from small `NSImage`s) → 3 elements, each opening as a 1-page `PDFDocument`; a path that doesn't exist → `.cannotOpen`; a text file renamed `.pdf` → `.cannotOpen`.
  - `MarkdownAssemblerTests`: `assemble([.text("A"), .blank, .unreadable, .text("D")])` equals `"<!-- Page 1 -->\n\nA\n\n<!-- Page 3 -->\n\n[PAGE 3 COULD NOT BE READ]\n\n<!-- Page 4 -->\n\nD\n"`; `assemble([])` and all-blank → `""`; `clean("```markdown\n# T\n```")` → `.text("# T")`; `clean("  [BLANK PAGE]\n")` → `.blank`; `clean("")` → `.blank`; `clean("a ``` b")` unchanged.

### Task 3: Claude client and prompt

**Files:** `Inkdown/Prompts.swift`, `ClaudeClient.swift`; `InkdownTests/ClaudeClientTests.swift`, `PromptsTests.swift`

**Interfaces:**
- `enum Prompts { static let system: String; static func user(page: Int, of total: Int) -> String }`

Request (check against the `claude-api` skill): `POST https://api.anthropic.com/v1/messages`; headers `content-type`, `x-api-key`, `anthropic-version: 2026-10-21`, `anthropic-beta: server-side-fallback-2026-07-01`; body `model`, `max_tokens: 16000`, `fallbacks: "default"`, `output_config: {effort: "medium"}`, `system`, and one user message whose content is a `document` block (`source: {type: "base64", media_type: "application/pdf", data: …}`) followed by a `text` block. No `thinking`, sampling or `tool_choice` fields. Timeout 240 s. Ephemeral session as in Glance.

`Prompts.system` must state every output rule from the spec's "The output file" section, plus: output only the transcription, no preface or closing remark, no code fence around it; do not add a title that isn't on the page; reply exactly `[BLANK PAGE]` for a page with nothing on it.

### Task 4: Converter

**Files:** `Inkdown/Converter.swift`; `InkdownTests/ConverterTests.swift`

**Interfaces:**
- `struct Converter { var transcribe: (Data, Int, Int) async throws -> PageAnswer; var retryDelays: [Double] = [2, 6, 15]; var maxAtOnce = 4; func convert(pages: [Data], progress: @escaping @Sendable (Int, Int) -> Void) async throws -> ConversionResult }` — `progress(done, total)` is called after each finished page.

Per page: `.busy` and `.offline` and `.failed` are retried after each delay in `retryDelays`; when retries run out, `.offline` and `.busy` stop the conversion (`ConversionError.stopped`), `.failed` makes the page `.unreadable`. `.noKey`, `.unauthorized`, `.noCredit` stop at once without retry. `.refused` and `.tooLarge` make the page `.unreadable` without retry. A `cutOff` answer keeps its text and appends `\n\n[PAGE N WAS CUT OFF]`. Task cancellation throws `ConversionError.cancelled`. When the conversion stops, pages not yet started are not requested. Results are assembled in page order with `MarkdownAssembler`; token counts are summed over every successful answer.

- [ ] **Failing tests** (fake `transcribe`, `retryDelays: [0, 0]`): all pages succeed in order even when page 1 finishes last (fake sleeps longer for page 1); never more than 4 calls in flight (fake counts); one page always `.failed` → 3 attempts, listed in `unreadablePages`, others present; `.busy` twice then success → page present; `.unauthorized` on page 1 of 20 with `maxAtOnce: 1` → throws `.stopped(.unauthorized)` and the fake was called once; `.refused` → unreadable after 1 call; cut-off marker; token sums; `.offline` on every try → throws `.stopped(.offline)`; cancelling the surrounding task → `.cancelled`; `progress` reaches `(total, total)`.
- [ ] Implement, tests pass, commit "Convert all pages with retries and a limit of four at once".

### Task 5: Queue and status

**Files:** `Inkdown/ConversionQueue.swift`; `InkdownTests/ConversionQueueTests.swift`

**Interfaces:**
- `enum QueueStatus: Equatable { case idle(last: String?); case converting(name: String, done: Int, total: Int) }` with `var menuTitle: String` ("Ready" or the last-result line; "Converting notes.pdf — page 3 of 12") and `var iconTitle: String` ("" or "3/12").
- `struct Job { let pdf: URL; let output: URL }`
- `enum JobOutcome: Equatable { case done(output: URL, result: ConversionResult); case failed(pdf: URL, error: ConversionError) }`
- `@MainActor final class ConversionQueue { init(split: @escaping (URL) throws -> [Data], makeConverter: @escaping () -> Converter, write: @escaping (String, URL) throws -> Void); var onStatus: ((QueueStatus) -> Void)?; var onOutcome: ((JobOutcome) -> Void)?; func add(_ job: Job); func cancelAll(); var isBusy: Bool { get } }`
- `static func lastLine(output: URL, result: ConversionResult) -> String` → `"notes.md — 12 pages, about $0.31"` (cost with two decimals; "1 page" singular; `", 2 pages unreadable"` appended when any).

Runs jobs one after another. `cancelAll` cancels the running job and drops waiting ones; a cancelled job reports no outcome and writes nothing. A result whose pages are all unreadable or blank still writes the file (it says so in the outcome line).
